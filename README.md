# PhoneCamera (Phone Cam Bridge)

**Превратите телефон в веб-камеру для ПК: по Wi-Fi, без приложений на телефоне**

Откройте ссылку в браузере телефона, разрешите доступ к камере, и картинка появится на ПК как виртуальная камера для Zoom, Discord, OBS, Telegram и других программ.

## Как это работает

На ПК запускается небольшой HTTPS-сервер. Телефон открывает его страницу, получает доступ к камере и отправляет видео по WebSocket. Сервер принимает поток и отдаёт его в виртуальную камеру через [pyvirtualcam](https://github.com/letmaik/pyvirtualcam).

```
Телефон (браузер)  ──HTTPS + WebSocket (TCP, Wi-Fi)──▶  server.py  ──▶  виртуальная камера  ──▶  Zoom / Discord / OBS
```

Видео передаётся JPEG-кадрами: каждый кадр самодостаточен, поэтому при потерях в сети картинка не «рассыпается». Если ПК не успевает обрабатывать кадры, старые отбрасываются и задержка не накапливается.

## Возможности

- **Без приложения на телефоне**: достаточно браузера.
- **QR-код и ссылка** в консоли для быстрого подключения.
- **Выбор камеры телефона**, разрешения, частоты кадров и качества JPEG прямо на странице.
- **Зеркалирование и поворот** картинки (0 / 90 / 180 / 270°).
- **Настройка выхода на ПК**: разрешение и FPS виртуальной камеры меняются на лету.
- **Управление камерой с ПК**: фокус, экспозиция, объектив и другие параметры, которые поддерживает камера телефона, настраиваются из терминального меню.
- **Работа в трее** на Windows: окно консоли можно скрыть и показать по клику на значок. Есть режим запуска сразу скрытым.
- **Автоматический сертификат**: самоподписанный HTTPS-сертификат создаётся под IP-адреса вашего ПК (HTTPS нужен браузеру для доступа к камере).
- **Статистика** в логах: входящие и выходящие кадры в секунду, пропущенные устаревшие кадры, время обработки, входящий битрейт.
- Быстрый декодер JPEG на OpenCV, при его отсутствии используется Pillow.

## Требования

- Windows (трей и консольное меню рассчитаны на Windows; сервер также содержит поддержку Linux через `v4l2loopback`).
- Установленный бэкенд виртуальной камеры, который поддерживает pyvirtualcam, например [OBS Studio](https://obsproject.com/) с функцией «Виртуальная камера».
- Телефон и ПК в **одной Wi-Fi сети**.
- Python 3 (если запускаете из исходников).

## Установка и запуск

### Из исходников

```bash
pip install -r requirements.txt
python server.py
```

В консоли появятся ссылка и QR-код. Откройте их на телефоне:

1. Откройте ссылку (или отсканируйте QR-код камерой телефона).
2. Браузер предупредит о сертификате. Это нормально, сертификат самоподписанный: нажмите **«Дополнительно» → «Всё равно перейти»**.
3. Нажмите **«Подключиться к ПК»** и разрешите доступ к камере.
4. В Zoom, Discord, OBS или другой программе выберите виртуальную камеру.

### Готовый .exe

Скачайте `server.exe` из раздела [Releases](../../releases) и запустите. Рядом с ним создастся папка `certs\` с сертификатом.

## Параметры запуска

```bash
python server.py --width 1920 --height 1080 --fps 30
```

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| `--host` | адрес, на котором слушает сервер | `0.0.0.0` |
| `--port` | порт HTTPS-сервера | `4829` |
| `--width`, `--height` | разрешение виртуальной камеры | `1920` × `1080` |
| `--fps` | частота кадров виртуальной камеры | `30` |
| `--backend` | бэкенд pyvirtualcam (`obs`, `unitycapture`, `v4l2loopback` и др.) | авто |
| `--cam-device` | устройство виртуальной камеры, например `/dev/video10` | авто |
| `--no-qr` | не показывать QR-код | выкл. |
| `--no-menu` | не показывать терминальное меню, только логи | выкл. |
| `--hidden` | стартовать скрытым в трее (Windows) | выкл. |

## Терминальное меню

Когда телефон подключился и пошло видео, логи прячутся в буфер и появляется меню:

| Клавиша | Действие |
| --- | --- |
| `1` | управление камерой телефона (параметры камеры и вывода на ПК) |
| `2` | логи |
| `3` | адрес для подключения и QR-код |
| `i` | показать адрес, пока телефон не подключён |
| `Ctrl+C` | выход из программы |

В разделе управления камерой: `↑` `↓` выбор пункта, `←` `→` изменить значение, `PgUp` / `PgDn` шаг в 10 раз больше, `Enter` переключить, `Esc` назад.

## Сборка .exe

В репозитории есть готовый файл сборки `server.spec`:

```bash
pip install -r requirements.txt
pyinstaller server.spec
```

Результат: `dist\server.exe`. Страница для телефона (`static\`) и значок упаковываются внутрь автоматически, а папка `certs\` создаётся рядом с .exe.

## Решение проблем

**Страница на телефоне не открывается.** Проверьте, что оба устройства в одной сети. Если в консоли указано несколько адресов, попробуйте другие: адреса вида `x.x.x.1` часто принадлежат виртуальным адаптерам (Docker, WSL, Hyper-V, VPN). Также проверьте, что брандмауэр Windows разрешает входящие подключения на порт `4829`.

**Браузер не даёт доступ к камере.** Страница должна быть открыта по `https://`. Пропустите предупреждение о сертификате, как описано выше.

**Нет виртуальной камеры в списке программ.** Установите OBS Studio или другой бэкенд, который поддерживает pyvirtualcam, и при необходимости укажите его через `--backend`.

**Картинка с задержкой или «рывками».** Уменьшите разрешение, FPS или качество JPEG на странице телефона. Статистика в логах покажет, сколько кадров пропускается.

**Сертификат перестал подходить.** Сертификат пересоздаётся автоматически, если у ПК изменились IP-адреса. Если нужно сделать это вручную, удалите папку `certs\`.
